# Claude Design의 `_ds` 토큰과 로컬 토큰이 같은 이름에 다른 값을 갖는다

| 항목 | 내용 |
|---|---|
| 위험도 | **6 / 10** |
| 분류 | 설정 충돌 (외부 디자인 시스템 ↔ 프로젝트 토큰) |
| 발견일 | 2026-08-08 |
| 상태 | 차단 장치 마련됨 (근본 해결 아님) |
| 관련 파일 | `styles/globals.css`, `docs/design-import/token-map.md` |

위험도 근거: 값이 틀려도 빌드·린트·타입 검사가 전부 통과하는 silent failure
구조(기준 7~8)지만, 실제로 틀린 코드가 들어가려면 사람이 `var(--…)`를 복사해야
하므로 한 단계 내려 **6**. 남은 섹션 8개와 Map 페이지에서 반복 노출되므로 **+1**,
매핑표라는 차단 장치를 만들어 **−1**.

## 1. 이슈 내용

### 증상

Claude Design 프로젝트 `04db054a-96f3-461f-a132-5a01ce27d59f`의 시안
`Home.dc.html`은 이런 식으로 토큰을 참조합니다.

```html
<div style="border-radius: var(--radius-xl); background: var(--primary);">
```

이 저장소에도 `--radius-xl`과 `--primary`가 **둘 다 존재합니다.** 그래서 위
마크업을 그대로 옮기면 에러 없이 렌더되지만 **의도한 것과 다른 화면이 나옵니다.**

### 충돌 목록

| 토큰 | 원격 `_ds` | 로컬 `globals.css` | 벌어지는 폭 |
|---|---|---|---|
| `--radius-xl` | 12px | 2rem (32px) | **2.7배** |
| `--radius-lg` | 10px | 1.25rem (20px) | 2배 |
| `--radius-md` | 8px | 0.875rem (14px) | 1.75배 |
| `--radius-sm` | 5px | 0.5rem (8px) | 1.6배 |
| `--primary` | `#dd3f57` | `oklch(0.5769 0.2277 18.5)` = `#e00b41` | 대비 4.27 ↔ 4.89 |
| `--hairline` | `#cccccc` | `oklch(0.8975 0 0)` = `#dddddd` | 로컬이 더 연함 |
| `--surface-soft` | `#f8f8f8` | `oklch(0.9761 0 0)` = `#f7f7f7` | 무시 가능 |

가장 눈에 띄는 것은 `--radius-xl`입니다. 시안에서 이 토큰은 **배너 컨테이너,
앱 기능 카드, 검색 인풋**에 쓰이는데, 로컬 값으로 렌더하면 12px이어야 할 모서리가
32px이 됩니다. 카드가 알약처럼 보이지만 **에러는 나지 않습니다.**

### 근본 원인

두 시스템이 같은 조상(Airbnb)에서 나왔지만 **다른 목적으로 전사**됐습니다.

| | 원격 `_ds` | 로컬 `globals.css` |
|---|---|---|
| 출처 | Figma 파일을 값 그대로 전사 | 그 위에 WCAG 검증을 적용 |
| 라운딩 근거 | "Nothing snapped to a grid" (주석 원문) | Tailwind 기본 스케일에 Airbnb 값을 재배치 |
| 명명 | Figma 프레임 이름 기준 | shadcn 시맨틱 슬롯 기준 |

로컬은 Tailwind v4의 `--radius-*` 네임스페이스를 쓰기 때문에 이름을 바꿀 수
없습니다. 원격도 우리가 고칠 수 있는 파일이 아닙니다. **양쪽 다 이름을 양보할 수
없는 구조**입니다.

## 2. 대응

원격 `_ds/*.css`를 저장소로 **복사하지 않기로** 했습니다. 대신 사람이 읽는
매핑표를 하나 만들고, 섹션 구현은 그 표만 참조합니다.

- `docs/design-import/token-map.md` — 원격 토큰 → 로컬 Tailwind 클래스 1:1 표
- 규칙: **섹션 구현에서 인라인 `style`과 `var(--…)`를 쓰지 않는다.** 전부
  Tailwind 유틸리티로 옮기고, 표에 없는 값이 필요하면 표를 먼저 고친다.

### 택하지 않은 대안

| 대안 | 기각 이유 |
|---|---|
| `_ds/styles.css`를 저장소에 복사해 import | 로컬 `:root`와 같은 이름이 충돌합니다. 나중에 로드된 쪽이 이깁니다. 어느 쪽이 이길지 CSS 로드 순서에 의존해 더 불안정합니다 |
| 원격 토큰을 `--ds-` 접두사로 바꿔 복사 | 시안의 `var(--radius-xl)`을 전부 손으로 고쳐야 하고, 원본이 갱신되면 다시 해야 합니다 |
| 로컬 토큰 값을 원격에 맞춤 | 기존 컴포넌트 4개와 테스트가 전부 깨지고, WCAG 검증 결과(`#e00b41`)를 버리게 됩니다 |

### 검증

`--primary` 두 값의 흰 텍스트 대비를 WCAG 2.x 상대 휘도 공식으로 계산했습니다.

```
원본 primary #dd3f57 위 흰 텍스트    4.27:1  큰텍스트만
로컬 primary #e00b41 위 흰 텍스트    4.89:1  AA 통과
```

기존 `docs/design-guide.md`가 기록한 `#e00b41` = 4.89:1이 그대로 재현되어
계산 방법이 맞음을 확인했습니다.

## 3. 해결 방안 및 더 나은 방법

**근본 해결이 아닙니다.** 매핑표는 사람의 주의에 의존하는 문서일 뿐이고,
시안에서 `style="border-radius: var(--radius-xl)"`을 복사해 붙이면 그대로
통과합니다.

### 더 나은 방법

1. **인라인 `style` 속성을 린트로 금지** — `react/forbid-dom-props`로
   `components/home/**`에서 `style`을 막으면 이 부류의 실수가 기계적으로
   차단됩니다. **비용이 낮아 다음 작업 때 넣을 가치가 있습니다.**
2. **토큰 값 대조 테스트** — 원격 `_ds` 토큰을 스냅샷으로 떠 두고 로컬 값과
   비교하는 테스트. 원격이 바뀌면 알 수 있지만, `DesignSync`가 필요해 CI에서
   돌리기 어렵습니다. 지금은 과합니다.

## 4. 남은 위험

- **Map 페이지에서 그대로 재발합니다.** `Map.dc.html`도 같은 `_ds`를 참조하므로
  같은 함정이 다시 나옵니다. 매핑표를 먼저 읽어야 합니다.
- **원격 시안이 갱신되면 매핑표가 낡습니다.** 갱신을 감지할 장치가 없습니다.
- 이번에 목록화한 것은 **Home이 실제로 쓰는 토큰만**입니다. `_ds`의 나머지
  토큰(`--stroke-*`, `--space-*`, `--switch-*` 등)은 대조하지 않았습니다.
