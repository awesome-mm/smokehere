## 결정 기록

### 행 전체를 `<button>`으로

시안은 `<div onClick>`입니다.

```html
<div onClick="{{ p.select }}" style="padding: 17px 20px; cursor: pointer; ...">
```

키보드로 고를 수 없습니다. **Home의 FAQ와 완전히 같은 문제**이고 같은 방식으로
고쳤습니다. 목록은 `<ul>/<li>`, 각 행은 `<button>`입니다.

`cursor: pointer`가 있어 마우스 사용자에게는 누를 수 있다고 보이는데 키보드로는
도달조차 못 하는 상태였습니다.

### 선택 표시는 `aria-current`

`aria-selected`는 listbox·tab 같은 **선택 위젯**의 속성입니다. 이 목록은 위젯이
아니라 항목을 열어 보는 내비게이션에 가까우므로 `aria-current="true"`를 씁니다.

시각적으로는 좌측 3px brand 액센트 + 배경 틴트로 표시합니다. 색상만이 아니라
**막대의 유무**로도 구분되므로 색각 이상 사용자에게도 전달됩니다.

### 거리에 기준을 붙여 읽히게

"320m"만 읽히면 무엇의 거리인지 알 수 없습니다. 화면에는 수치만 두고,
보조기술에는 기준을 덧붙였습니다.

```tsx
<span aria-hidden="true">{spot.distanceLabel}</span>
<span className="sr-only">기준 위치에서 {spot.distanceLabel}</span>
```

운영시간 배지도 같은 이유로 `<span className="sr-only">운영 시간 </span>`을
앞에 붙였습니다. "24시간"만 읽히면 맥락이 없습니다.

### 결과 개수를 `aria-live`로 알림

필터를 바꾸면 목록이 통째로 바뀌는데, 화면을 못 보면 결과가 몇 건이 됐는지
알 수 없습니다. 카운트 문단에 `aria-live="polite"`를 걸었습니다.

목록 전체가 아니라 **개수만** 알립니다. 목록에 live를 걸면 항목이 바뀔 때마다
전부 읽혀 수다스러워집니다.

### 주소 말줄임

`truncate`(`text-overflow: ellipsis`)는 **시각적으로만** 자릅니다. DOM에는 전체
문자열이 남아 스크린리더는 주소를 끝까지 읽습니다. 정보 손실이 없습니다.

## "내 위치에서 찾기" — 조용히 실패하지 않기

시안은 권한 거부·미지원 시 **아무 말 없이** 좌표를 강남역으로 바꿉니다.

```js
navigator.geolocation.getCurrentPosition(
  (pos) => this.setState({ origin: [...] }),
  () => this.setState({ origin: [37.4979, 127.0276], city: "서울", query: "" })
);
```

사용자는 왜 갑자기 강남역 기준이 됐는지 알 수 없습니다. 상태를 명시적으로
전달하도록 바꿨습니다.

| 상태 | 안내 문구 |
|---|---|
| `locating` | 현재 위치를 확인하는 중입니다. |
| `located` | 현재 위치를 기준으로 거리를 다시 계산했습니다. |
| `denied` | 위치 권한이 없어 서울 강남역을 기준으로 표시합니다. |
| `unsupported` | 이 브라우저는 위치 확인을 지원하지 않아 서울 강남역을 기준으로 표시합니다. |

`role="status"`로 렌더해 보조기술에도 전달되고, 요청 중에는 버튼이 비활성됩니다.

**위치 정보는 화면 밖으로 나가지 않습니다.** 거리 계산에만 쓰이고 어디에도
저장하거나 전송하지 않습니다. 실제 요청 로직은 #18에서 페이지가 소유합니다.

## 원본과 의도적으로 다른 부분

| 항목 | 원본 | 구현 | 이유 |
|---|---|---|---|
| 행 요소 | `<div onClick>` | `<ul>/<li>` + `<button>` | 키보드로 선택 가능해야 합니다 |
| 선택 표시 | 배경색 + 좌측 액센트 | 동일 + `aria-current` | 보조기술 전달 |
| 거리 | "320m" | + sr-only "기준 위치에서" | 맥락 없이 읽히지 않게 |
| 운영시간 배지 | "24시간" | + sr-only "운영 시간" | 같은 이유 |
| 결과 개수 | 정적 텍스트 | `aria-live="polite"` | 필터 변경 결과 전달 |
| 위치 실패 | 조용히 강남역으로 | `role="status"` 안내 | 원인을 알 수 있어야 합니다 |
| 형태 배지 색 | `kindColors()` 3종 | 배경은 항상 연한 면, 글자색만 구분 | `brand` 배경 위 텍스트 금지 규약 |
