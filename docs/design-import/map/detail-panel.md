## 제보 버튼 — 문구를 바꿨습니다

시안은 버튼을 누르면 라벨이 바뀝니다.

```js
report: () => this.setState({ reported: true }),
reportLabel: st.reported ? "제보가 접수되었습니다" : "정보가 다릅니다 · 제보하기",
```

**아무것도 전송하지 않습니다.** 상태 하나만 바뀔 뿐인데 "접수되었습니다"라고
말합니다. 사용자는 잘못된 정보를 신고했다고 믿고 화면을 떠나지만 실제로는
어디에도 전달되지 않았습니다.

받을 곳이 생길 때까지는 준비 중임을 그대로 알립니다.

> 제보 기능은 아직 연결되지 않았습니다. 준비되면 이 화면에서 바로 보낼 수 있습니다.

버튼 자체는 남겼습니다. 이 자리에 제보가 들어온다는 것을 보여 주는 편이,
아예 없애 놓고 나중에 끼워 넣는 것보다 낫다고 판단했습니다.

## 결정 기록

### 모달이 아니다

지도 위에 겹치지만 배경을 가리지 않고 포커스를 가두지 않습니다. 패널이 떠
있는 동안에도 좌측 목록과 필터를 계속 쓸 수 있어야 합니다.
`role="region"` + `aria-labelledby`로 이름 있는 영역으로 노출합니다.

### 포커스는 옮기되 가두지는 않는다

목록 항목을 **명시적으로 활성화**해서 열리는 패널이므로, 포커스를 패널로
옮겨 키보드 사용자가 곧바로 길찾기까지 도달하게 했습니다
(`tabIndex={-1}` + `focus()`).

Esc로 닫습니다. 포커스를 가두지 않으므로 패널 밖에 포커스가 있어도 동작하도록
`document` 수준에서 keydown을 받습니다.

### 상태 초기화는 effect가 아니라 `key`

다른 흡연구역을 고르면 제보 안내가 초기화돼야 합니다. 처음에는
`useEffect(() => setReportNoticed(false), [spot.id])`로 썼는데 린트가 잡았습니다.

```
react-hooks/set-state-in-effect
  34 |     setReportNoticed(false)
     |     ^^^^^^^^^^^^^^^^ Avoid calling setState() directly within an effect
```

React가 권하는 방식은 **prop이 바뀌면 key로 다시 마운트**하는 것입니다.
부모가 `key={spot.id}`를 넘기면 상태 초기화와 포커스 이동이 한 번에 해결됩니다.
컴포넌트 상단 주석에 이 요구사항을 명시했습니다.

### 길찾기는 외부 링크

```
https://www.google.com/maps/dir/?api=1&destination=위도,경도
```

**API 키가 필요 없는 URL 스킴**이라 지도 연동을 미룬 이번 범위에 포함해도
문제가 없습니다. 새 창으로 열리므로

- `rel="noopener noreferrer"`
- `ExternalLink` 아이콘
- `sr-only`로 "(구글 지도, 새 창에서 열림)"

를 함께 붙였습니다. 새 창이 열린다는 사실은 클릭 전에 알 수 있어야 합니다.

### 사실 목록은 `<dl>`

라벨-값 쌍 5개이므로 정의 목록이 맞습니다. 시안은 `<div>` + `<span>` 두 개라
라벨과 값의 관계가 마크업에 없습니다.

### 애니메이션

시안의 `@keyframes cardIn`(10px 아래에서 페이드) 대신 이미 설치된
`tw-animate-css`의 `animate-in fade-in slide-in-from-bottom-2`를 씁니다.
새 키프레임을 정의하지 않았습니다. `prefers-reduced-motion`은
`styles/globals.css`의 전역 규칙이 처리합니다.

### 반응형

시안은 데스크톱 전용(우측 330px 고정)입니다. 좁은 화면에서는 하단에서
올라오는 형태로 두고, `lg` 이상에서 시안대로 우측에 붙입니다.

```
absolute inset-x-4 bottom-4 max-h-[70%]
lg:inset-x-auto lg:top-4 lg:right-5 lg:bottom-5 lg:w-[330px]
```

## 원본과 의도적으로 다른 부분

| 항목 | 원본 | 구현 | 이유 |
|---|---|---|---|
| 제보 결과 문구 | "제보가 접수되었습니다" | "아직 연결되지 않았습니다" | 전송하지 않으면서 접수됐다고 말하지 않습니다 |
| 닫기 버튼 | `×` 문자만 | `aria-label="상세 정보 닫기"` + lucide `X` | 아이콘 단독 버튼에는 이름이 필요합니다 |
| 사실 목록 | `<div>` + `<span>` | `<dl>/<dt>/<dd>` | 라벨-값 관계 |
| 길찾기 | `target="_blank"`만 | + `rel` + 외부 링크 표시 | 보안·예측 가능성 |
| 닫기 수단 | 버튼만 | 버튼 + Esc | 키보드 |
| 라운딩 | `--radius-xl` (12px) | `rounded-md` (14px) | 토큰 이름 충돌 (매핑표) |
| 레이아웃 | 우측 330px 고정 | 좁은 화면은 하단 | 반응형 필수 규약 |

## 남은 과제

- **테스트 미작성** (#19) — 열림/닫힘, Esc, 제보 안내, 길찾기 URL
- **브라우저 육안 확인 미실행** (#19)
- **닫은 뒤 포커스가 목록으로 돌아가지 않습니다.** 패널을 열 때는 포커스를
  옮기지만 닫을 때는 원래 항목으로 되돌리지 않습니다. 부모가 어떤 항목에서
  열렸는지 알아야 해서 #18에서 함께 볼 항목입니다.
- `animate-in` 계열 유틸리티가 실제로 생성되는지 빌드 CSS로 확인하지 않았습니다.
