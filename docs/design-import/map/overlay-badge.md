# 지도 오버레이 배지

> 상태: **완료** (브라우저 확인은 #19) · 태스크 #17 · 2026-08-09

## 범위

지도 영역 좌측 상단에 떠 있는 지역·표시 개수 배지.

## 원본

`Map.dc.html` → `cityLabel` / `visibleLabel` 오버레이 블록

## 구현 대상

`components/map/map-overlay-badge.tsx`

## 위치 — 62px의 근거가 사라졌습니다

시안은 `top: 18px; left: 62px`입니다. **62px는 Leaflet 줌 컨트롤(좌측 상단
+/− 버튼)을 피하려고 비워 둔 폭**입니다.

지도 라이브러리를 쓰지 않는 지금은 그 자리에 아무것도 없어 62px만큼 뜬 배지가
어색합니다. 상세 패널과 같은 리듬인 16px(`top-4 left-4`)로 맞췄습니다.

**지도를 붙일 때 되돌아볼 지점입니다.** 줌 컨트롤을 지도 좌측 상단에 두면
다시 비켜야 합니다.

## 도시 라벨 — 로마자로 표기

시안은 이렇게 만듭니다.

```js
cityLabel: st.city === "전체" ? "KOREA" : st.city.toUpperCase(),
```

`"서울".toUpperCase()`는 **"서울"** 그대로입니다. 한글에는 대소문자가 없습니다.
결과적으로 "전체"만 `KOREA`로 나오고 나머지는 한글이 나옵니다.

"전체"를 굳이 `KOREA`로 바꿔 둔 걸 보면 **로마자 대문자를 의도**한 것이 분명하고,
`--font-alt` + 넓은 자간(0.16em)이라는 조판도 로마자 대문자에 맞춘 것입니다.
한글에 0.16em 자간을 주면 "서 울"처럼 벌어집니다.

로마자 매핑 테이블을 두되, **보조기술에는 한글이 읽히게** 했습니다.

```tsx
<span aria-hidden="true">SEOUL</span>
<span className="sr-only">서울</span>
```

| 선택지 | 값 |
|---|---|
| 전체 | KOREA |
| 서울 | SEOUL |
| 부산 | BUSAN |
| 인천 | INCHEON |
| 대구 | DAEGU |

도시가 늘어나면 이 표도 함께 늘려야 합니다. `Record<CityOption, string>`이라
새 도시를 추가하면 타입이 빠뜨림을 잡아 줍니다.

## 개수를 `aria-live`로 두지 않은 이유

사이드바의 "N개 결과 · 가까운 순"이 이미 `aria-live="polite"`입니다(#15).
같은 수치라 여기에도 걸면 필터를 바꿀 때마다 **같은 숫자를 두 번** 읽습니다.
배지는 시각적 보조에 가까우므로 live로 두지 않았습니다.

## 대비 계산

배지 배경은 반투명(`bg-background/95`)이라 자리표시자 회색 위에 합성된 실제
색으로 계산했습니다.

```
배지 실제 배경 RGB: 254,254,254

muted-foreground #6a6a6a (지역 라벨)   5.38:1  AA 통과
ink #222222 (개수)                   15.82:1  AA 통과
control #929292 (테두리)               3.09:1  비텍스트 3:1 통과
```

시안의 테두리는 `--grey-500`(#707070)이었는데 로컬 `control`(#929292)로
매핑해도 1.4.11의 3:1을 넘습니다.

## 원본과 의도적으로 다른 부분

| 항목 | 원본 | 구현 | 이유 |
|---|---|---|---|
| 위치 | `left: 62px` | `left-4` (16px) | 62px는 Leaflet 줌 컨트롤 회피용이었습니다 |
| 도시 라벨 | `toUpperCase()` — 한글엔 무효 | 로마자 매핑 + sr-only 한글 | 의도한 표기를 실제로 구현 |
| 배경 | `rgba(255,254,251,0.94)` | `bg-background/95` | 토큰 사용 |
| 라운딩 | `10px` | `rounded-md` (14px) | 매핑표 |
| 개수 알림 | 없음 | live 없음 (사이드바가 담당) | 중복 낭독 방지 |
