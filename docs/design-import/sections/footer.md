## 대비 계산

**이 섹션에서 가장 중요한 부분입니다.** 로컬 텍스트 위계는 전부 흰 배경 기준이라
그대로 뒤집어 쓸 수 없습니다.

| 전경 | 배경 | 대비 | 판정 |
|---|---|---|---|
| `#dddddd` (`on-inverse`) | `#222222` (`ink`) | **11.71:1** | ✅ 채택 |
| `#d9d9d9` (원본 grey-300) | `#1c1b1b` (원본 grey-900) | 11.27:1 | ✅ 원본도 통과 |
| `#c1c1c1` (`border-strong`) | `#222222` | 8.84:1 | ✅ |
| `#929292` (`on-inverse-muted`) | `#222222` | **5.11:1** | ✅ 채택 (하단 바·컬럼 헤드) |
| `#707070` (**원본 하단 바**) | `#1c1b1b` | **3.21:1** | ❌ 12px 텍스트에 미달 |
| `#6a6a6a` (`muted-foreground`) | `#222222` | **2.94:1** | ❌ 쓰면 안 됨 |

원본은 하단 저작권 바와 SERVICE/DATA 컬럼 헤드에 `--grey-500`(#707070)을 쓰는데,
12px·10.5px 텍스트에서 3.21:1은 AA(4.5:1)에 미달합니다.

`muted-foreground`(#6a6a6a)를 무심코 가져다 쓰면 **2.94:1로 더 나빠집니다.**
반전 면에서는 기존 텍스트 토큰을 쓸 수 없다는 뜻이라, 전용 토큰을 추가했습니다.

```css
/* styles/globals.css */
--on-inverse: oklch(0.8975 0 0);        /* #dddddd — ink 위 11.71:1 */
--on-inverse-muted: oklch(0.66 0 0);    /* #929292 — ink 위 5.11:1 */
```

## 결정 기록

### 컬럼 헤드를 `<h2>` + `aria-labelledby`로 연결

원본은 `<div>`입니다. 시각적으로 작지만 링크 그룹의 제목 역할을 하므로 heading으로
올리고, 목록·내비게이션과 `aria-labelledby`로 연결했습니다.

`<nav aria-label="서비스">`와 보이는 제목을 **함께** 두면 이름이 두 번 붙어
"서비스, 서비스 소개…"처럼 읽힙니다. `aria-label`을 빼고 `aria-labelledby`로
보이는 제목을 가리키게 했습니다.

### "최종 갱신"을 상수로 분리

```tsx
/** 원본 시안에 박혀 있던 값입니다. 실제 갱신일과 연결된 데이터가 아직 없습니다. */
const LAST_UPDATED = "2026.08.01"
```

데이터 갱신 파이프라인이 없어 하드코딩입니다. 상수로 빼 두면 나중에 실제
갱신일로 바꿀 지점이 한 곳으로 모입니다.

### 푸터 로고는 흰색

원본도 푸터 마크만 `--white`를 씁니다. 헤더의 `brand`(#ff385c)를 ink 배경에
올리면 눈에 띄지 않습니다.
