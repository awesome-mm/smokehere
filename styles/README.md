# 스타일 · 디자인 시스템 출처

이 폴더의 `globals.css`에는 SmokeHere의 디자인 토큰 전체가 정의돼 있습니다.
**토큰 체계는 Airbnb의 공개 웹 디자인 언어를 분석해 자체 구현한 것입니다.**

사용 규칙과 결정 근거는 `docs/design-guide.md`를 보세요. 이 문서는 **무엇을
참고했고 어디까지가 우리 것인지**를 밝힙니다.

## 무엇을 참고했나

Airbnb 공개 웹(airbnb.com)의 디자인 언어에서 다음 체계를 참고했습니다.

| 영역 | 참고한 내용 |
|---|---|
| 색상 | Rausch 계열 브랜드 컬러, 중성 텍스트 위계(#222222 계열), 표면·헤어라인 톤 |
| 타이포그래피 | 크기·굵기·행간을 한 토큰에 묶는 방식과 17단계 스케일 구성 |
| 라운딩 | 4 / 8 / 14 / 20 / 32px 단계와 "하드 코너 없음" 원칙 |
| 그림자 | 단일 티어 — 깊이는 사진과 라운딩이 만든다는 접근 |
| 여백 | "열린 상단, 조밀한 목록"이라는 마켓플레이스 리듬 |

**코드나 에셋을 가져오지 않았습니다.** Airbnb의 CSS·컴포넌트·아이콘·이미지는
일절 사용하지 않았고, 위 체계를 참고해 `globals.css`에 직접 작성했습니다.

## 무엇을 바꿨나

원본을 그대로 옮기지 않았습니다. 접근성 요구 때문에 의도적으로 벗어난 지점이
있습니다.

- **브랜드 컬러를 둘로 분리했습니다.** 원본 Rausch(`#ff385c`)는 흰 텍스트 대비가
  3.52:1로 WCAG AA(4.5:1)에 미달합니다. 비텍스트 전용 `brand`(`#ff385c`)와
  텍스트를 얹는 면에 쓰는 `brand-strong`(`#e00b41`, 4.89:1)으로 나눴습니다.
- **호버를 밝게가 아니라 어둡게** 처리합니다. 밝히면 대비가 무너집니다.
- **비활성 라벨은 흰색이 아니라 ink**입니다. 흰색은 `brand-subtle` 위에서 1.37:1로
  읽히지 않습니다.
- **포커스에 링과 offset을 씁니다.** 원본은 글로우 없는 테두리지만, 키보드 포커스
  가시성(WCAG 2.4.11)을 위해 바꿨습니다.
- **다크 모드가 없습니다.** Airbnb 공개 웹과 같은 선택입니다.

전체 목록과 이유는 `docs/design-guide.md`의 "원본에서 의도적으로 벗어난 부분"에
있습니다.

## 폰트

**Airbnb Cereal VF는 Airbnb 전용 유료 서체라 사용하지 않았습니다.**
가장 가까운 오픈소스 대체인 **Inter**를 씁니다.

| 폰트 | 라이선스 | 용도 |
|---|---|---|
| [Inter](https://github.com/rsms/inter) | SIL Open Font License 1.1 | 본문·제목 전체 |
| [Geist Mono](https://vercel.com/font) | SIL Open Font License 1.1 | 코드·수치 |

둘 다 `next/font/google`로 로드합니다 (`app/layout.tsx`).

## 법적 고지

**SmokeHere는 Airbnb와 어떤 제휴·후원·승인 관계도 없습니다.**

- "Airbnb"와 "Rausch"는 Airbnb, Inc.의 상표입니다. 이 저장소에서는 **설명 목적**
  으로만 언급하며, 상표 사용을 주장하지 않습니다.
- Airbnb의 디자인 시스템(DLS)은 오픈소스로 배포된 적이 없습니다. 이 프로젝트는
  공개된 웹사이트에서 관찰 가능한 디자인 언어를 참고했을 뿐, 비공개 자료나
  내부 문서에 접근하지 않았습니다.
- 색상 값이나 크기 수치 같은 사실 정보 자체는 일반적으로 저작권 보호 대상이
  아니지만, **상용 서비스로 배포하기 전에는 브랜드 정체성이 충분히 구별되는지
  법적으로 검토하는 것을 권합니다.** 특히 브랜드 컬러를 그대로 쓰는 것은
  혼동 가능성이 있습니다.

`globals.css`에 정의된 토큰과 이 저장소의 코드는 프로젝트 라이선스를 따릅니다.
